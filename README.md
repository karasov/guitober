# GUItober — сайт-архив

Статический сайт без базы данных и админки. Весь контент — в `content/` (JSON + Markdown),
страницы собираются из него автоматически.

## Как посмотреть локально

Открыть `index.html` двойным кликом — сайт работает прямо с диска.
(или `python3 -m http.server` в этой папке → http://localhost:8000)

## Как вносить изменения

1. Поменять файлы в `content/`.
2. Запустить сборку: `python3 tools/build.py`
   - оптимизирует новые картинки/видео в `media/` (превью webp, полноразмерные webp, mp4);
   - пересобирает `assets/js/data.js` — единый бандл контента.
   Если менялись только тексты/ссылки: `python3 tools/build.py --data` (секунды).

Нужны Python 3 + Pillow, для видео — ffmpeg.

## Структура

```
content/
  site.json                 годы, год по умолчанию, контакты, футер, тексты интерфейса (ui.ru, позже ui.en)
  people.json               общие данные людей (один человек = одна запись на все годы)
  years/<год>/
    year.json               название, даты, цвет панели, логотип, медали и пороги, статус (archive / upcoming)
    prompts.json            список промптов: day, title, titleEn, text (путь к .md), image
    prompts/NN.md           оригинальный текст поста дня из Telegram
    prompts/NN.jpg          картинка-вайрфрейм из поста
    rules.md                правила года
    works.json              работы: id, author (id из people.json), file, days
    works/<ник>/…           исходные файлы работ
    assets/                 logo.png, prompts.png, rules.png, modes.png, medals/*.svg
assets/                     css, js, логотипы футера (assets/brand)
media/                      генерируется сборкой — руками не править
tools/build.py              сборка
tools/import_sources.py     разовый импорт из экспорта Telegram и папок участников
```

## Частые правки

**Ссылка участника** — `content/people.json`:
```json
{ "id": "podusenko", "name": "Stanislav Podusenko", "telegram": "podusenko",
  "avatar": null, "link": { "label": "Behance", "url": "https://behance.net/…" } }
```
Пустой `url` показывается как неактивная «рыба».
Несколько ссылок — вместо `link` поле `links`: `[{ "label": "Behance", "url": "…" }, { "label": "ArtStation", "url": "…" }]`.

**Аватар** — положить файл, например `content/avatars/podusenko.jpg`, и прописать
`"avatar": "content/avatars/podusenko.jpg"`. Без аватара рисуется круг с инициалами.

**Работа на несколько дней** — одна запись в `works.json`, дни списком:
```json
{ "id": "2025-podusenko-07", "author": "podusenko", "file": "works/podusenko/podusenko_05-07.jpg", "days": [5, 6, 7] }
```
Работа покажется в днях 05, 06, 07 и засчитается как 3 промпта. Пустой `days` — работа
видна только в галерее участника («вне промптов»).

**Вычисляется автоматически** (не хранится руками): число закрытых промптов участника
(уникальные дни по его работам), рейтинг и порядок работ внутри дня, медаль по порогам
из `year.json` → `medals`. Ручное переназначение медали: `"medalOverrides": { "risha_frog": "legendary" }`.
В разделе «По дням» показываются работы всех, кто публиковался в чате. Свой блок в «Участниках»,
медаль, внешнюю ссылку и переход к блоку из попапа получают только участники от `minPromptsToPublish` (7) промптов;
у остальных в попапе — только аватар, имя и Telegram.
День без собственного промпта (18 «Рефакторинг») помечен в `prompts.json` как `"noWorks": true` — в нём не показываются работы.

**Новый год** — добавить год в `site.json → years`, создать `content/years/<год>/` по образцу
2026 (year.json, prompts.json, rules.md, works.json, assets/), запустить сборку.

**Цвет года** — `year.json → color` (фон верхней панели) и `colorText` (текст на ней).

**Шрифты** — общий текст: Inter, акцентный (номера, заголовки, имена): LINE Seed JP — во всех годах
(Google Fonts, подключены в `index.html`). Акцентный шрифт можно сменить для отдельного года в
`year.json → font` (`family`, `weight`). Bender лежит в `assets/fonts/` про запас (@font-face в `style.css`).
Номер дня на странице «По дням» — тонкое начертание, высота цифр равна диаметру аватарки
(переменная `--avatar` в `style.css`).

**Размер логотипа года** — `year.json → logoScale` (1 = исходный размер, 0.5 = вдвое меньше).
Блок с логотипом во всех годах одной высоты (высота логотипа 2024/2025); логотип меньшей высоты центрируется по вертикали.
`year.json → logoBleed: true` — логотип начинается от левого края страницы (2026; сам файл подрезан слева на 15 px, оригинал — `assets/logo-original.png`).

**Страница «Промпты»** начинается с заголовка и текстового списка всех промптов года (1–4 колонки в зависимости от ширины экрана).
Выходные (сб/вс октября этого года) вычисляются автоматически и выделяются цветом `year.json → accent`.

Заголовки страниц («Все работы участников», «Список промптов») и подзаголовок — в `site.json → ui.ru`; ссылка на чат — `site.json → communityChat`.

**Недоступные разделы года** — `year.json → disabledSections`, например `["days", "participants"]` (2026): пункты меню серые и некликабельные, по умолчанию открывается первый доступный раздел.

**Страница правил** — `year.json → rulesAside` (Markdown-файл, текст во второй колонке, размер как у списка промптов) и `rulesNote` (Markdown-файл, текст в акцентной рамке под правилами).

## Режим правок работ

Откройте `index.html?edit` (к адресу файла допишите `?edit` перед `#`), например:
`…/guitober-site/index.html?edit#/2024/days`

- На каждой превью видно имя файла и дни, к которым привязана работа.
- В попапе работы внизу панель: кнопки дней 01–31 (чёрные — выбранные, в серой рамке — как было изначально),
  «Удалить работу» / «Вернуть работу», «Отменить правки этой работы». Удалённые работы в режиме правок
  видны с красной рамкой, на обычном сайте их нет.
- Правки сохраняются в этом браузере; внизу слева панель «Режим правок»: «Скопировать» (JSON в буфер),
  «Скачать edits.json», «Очистить».
- Применить: `python3 tools/apply_edits.py edits.json` → `python3 tools/build.py`.
  Применённые наборы правок храним в папке `edits/`.
